## Jenkins
In OSCP-style labs, Jenkins may appear as:
- An exposed web application
- A misconfigured CI/CD service
- A place containing credentials
- A path to command execution

Your first questions:
1. Is Jenkins accessible?
2. What version is running?
3. Is login required?
4. Are anonymous users allowed?
5. What plugins exist?
6. Are jobs visible?
7. Are secrets exposed?
